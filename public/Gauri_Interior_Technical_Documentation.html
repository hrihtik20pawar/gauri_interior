1. Project Overview

What is Gauri Interior Pvt. Ltd.?

Gauri Interior Pvt. Ltd. is a Mumbai-based premium interior design, renovation, and turnkey project execution company, part of the Gauri Group of Companies (established 2012, legacy since 1993). The company offers interior design services for residential, commercial, hospitality, healthcare, educational, and retail spaces across India.

This documentation covers the official corporate website — a modern, animated single-page application (SPA) built to showcase the company's projects, services, team, and brand identity.

6.2 Lenis Smooth Scroll

Integration Details

  • Initialized in App.tsx with duration: 1.2 and custom easing
  • Integrated with GSAP ticker: gsap.ticker.add((time) => lenis.raf(time * 1000))
  • Connected to ScrollTrigger: lenis.on('scroll', ScrollTrigger.update)
  • Disabled on mobile (< 768px) for performance
  • Tab switching fix: visibilitychange event triggers ScrollTrigger.refresh()
  • Accessible via useLenis() context hook

6.3 Animation Pattern

Consistent Pattern: Most sections use an IntersectionObserver that triggers an animated boolean state, which gates GSAP animations via useGSAP dependency. This ensures animations only fire when sections scroll into view — not on page load.

9.2 Image Optimization

  • AVIF Format: Modern, high-compression image format (batch converted via scripts/convert-to-avif.cjs)
  • Lazy Loading: All images except hero LCP use loading="lazy"
  • Preloading: Hero image preloaded in index.html for LCP optimization
  • Sharp Processing: AVIF quality 80 (90 for PNG), with size reduction reporting

9.3 CSS & Runtime Optimizations

  • GPU Acceleration: will-change and contain on animation-heavy elements
  • Lenis Mobile Disable: Smooth scroll disabled on mobile for better performance
  • Chunk Size Warning: Set to 600KB limit in Vite config
  • esbuild Minification: Fast JS and CSS minification
  • Performance Monitoring: usePerformance hook tracks LCP, CLS, FID via PerformanceObserver
